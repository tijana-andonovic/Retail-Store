🛍️#Retail Store
Retail Store is a responsive e-commerce web application built with React. It allows users to browse products, view product details, create an account, log in, and manage their shopping cart.

✨##Features
- Dynamic product listing and product details
- Navigation using React Router
- User registration and login forms with validation
- Shopping cart management with quantity updates and total price calculation
- Global state management using Context API
- Data persistence using localStorage and sessionStorage
- API integration with loading and error handling
- Responsive user interface
🛠️##Technologies
- ⚛️ React
- 💻 JavaScript
- 🎨 HTML5 & CSS3
- 🧭 React Router
- 🔄 Context API
- 🌐 REST API
- 💾 localStorage & sessionStorage
- 🔧 Git & GitHub
🚀##Getting Started
1. Clone the repository.
2. Install dependencies using npm install.
3. Start the development server using npm run dev.
